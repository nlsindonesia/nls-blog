Panduan Format CBT NLS

Gunakan format berikut. Tipe soal otomatis terdeteksi (opsional # TIPE: pg_kompleks). Pembahasan gunakan #### Pembahasan:. Skor opsional: # SKOR: 4 dan # PENALTI: -1. Gambar opsional: [img:URL_GAMBAR]. 

# SKOR: 4
# PENALTI: -1
::Soal 1:: Ibukota RI?
[img:https://web.com/gambar.jpg]
{
= Jakarta
~ Bandung
}
#### Pembahasan: Jakarta secara historis.
# TIPE: pg_kompleks
# SKOR: 5
::Soal 2:: Termasuk buah?
{
= Apel
~ Bayam
= Jeruk
}

Pilih / Tarik File .doc atau .docx

Download file Anda dari Google Docs (File > Download > Microsoft Word), lalu unggah ke sini.

Struktur Tabel Wajib

Tabel di file Anda harus persis berisi 6 kolom dari kiri ke kanan (tanpa nomor). Header bebas. Urutan:

  1. Tipe Soal (PG / Essai / Isian)
  2. Pertanyaan (Boleh ada gambar)
  3. Pilihan Ganda (Enter tiap opsi)
  4. Kunci Jawaban (A/B/C dll)
  5. Poin Benar (Angka)
  6. Pembahasan (Penjelasan)
